# Benjamin Wagner — Portfolio Website

A responsive static portfolio made with HTML, CSS, and JavaScript. It is designed for GitHub Pages and requires no build tools.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the whole `media` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Your website will appear at `https://YOUR-USERNAME.github.io/portfolio/`.

## Add your media

Keep the filenames below exactly the same, or change the corresponding paths in `index.html`.

- `media/hero-running.jpg` — optional wide hero background image. If you don't add it, the hero still has a dark green background.
- `media/running-vest-1.pdf` — first running vest PDF.
- `media/running-vest-2.pdf` — second running vest PDF.
- `media/sewing-1.jpg` and `media/sewing-2.jpg` — sewing project photos.
- `media/personal-1.jpg`, `media/personal-2.jpg`, `media/personal-3.jpg` — three personal project images.

The PDF cards are styled previews that open the corresponding PDF in a new tab. The three project image slots show an upload prompt until you add an image with the matching filename.

## Personalize the text

Open `index.html` and search for the placeholder project titles/descriptions. Change `YOUR-EMAIL@example.com` to the email address you want to publish, or remove the contact links if you prefer not to show an email publicly.

## Privacy reminder

GitHub Pages sites published from a public repository are publicly accessible. Only put files online that you're comfortable sharing publicly. You can build and preview everything locally before publishing.
